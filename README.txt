WAHAB TRADER — Android starter project\n\nThis is a UI prototype/source project, not a compiled APK. It intentionally does not generate trading calls: no verified live candle feed is connected. The QuotexAPI README supplied by the user says its endpoints/data handling are incomplete, so do not enter Quotex credentials or SSID.\n\nTo build: open this folder in Android Studio, allow Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s). A debug APK is created under app/build/outputs/apk/debug/. Official guide: https://developer.android.com/studio/build\n
